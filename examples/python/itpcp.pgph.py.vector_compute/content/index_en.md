# Computing with Vectors

## Introduction

This task refers to `basis1` from week 1. The same mathematical operations should be performed, this time with vectors.

In the submission version of the example, no output should be made in the console.

## Task

 1. Create in the script `vector_compute` (File: `vector_compute.py`) the following vectors:

|Variable|Value|
|----|:----------------------------------------|
|`x` | Vector of integers from $1$ to $5$|
|`y` | Vector of integers from $2$ to $6$|

2. Now perform the same operations with these vectors as in `basis1.py`. Name the created
variables the same and add the suffix `_vec`, so `diff` becomes `diff_vec`, for example.


## Hints

* When creating vectors, pay attention to whether the endpoint is included (see [numpy.arange]).
