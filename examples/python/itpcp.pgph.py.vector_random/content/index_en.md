# Generating Random Numbers

## Introduction

In this example, you will get an introduction to generating random numbers with Python. Since it is extremely important to be able to navigate the Python documentation, not all commands are listed for the
following subtask.


## Task

1. Create in the file `vector_random.py` the following vectors with random numbers:

| Variable      |Value|
|---------------|:-----------------------------------------|
| `rand1`       | 10 uniformly distributed random numbers in the half-open interval $[0,1)$ |
| `rand2`       | 20 normally distributed random numbers (mean 0, standard deviation 1) |
| `rand_normal` | 20 normally distributed random numbers (mean 5, standard deviation 0.2) |
| `i_min`       | 5 |
| `i_max`       | 15 |
| `randint1`    | 30 uniformly distributed integer random numbers in the closed interval `[i_min,i_max]` |
